# 📚 Sistema de Biblioteca Acadêmica

Projeto em SQLite para Banco de Dados I (UESB).

## 📌 Descrição
Modelagem em 3FN para controle de acervos, empréstimos e consultas.

## 🛠️ Como Usar
Rode `banco_biblioteca.sql` via terminal (`sqlite3 bd.db < banco_biblioteca.sql`) ou no sqliteonline.com.
